# Primitive DB

## Управление таблицами

Для управления таблицами используются следующие команды:

| Команда | Описание |
|---|---|
| `help` | Вывести справочную информацию |
| `create_table <имя_таблицы> <столбец1:тип> <столбец2:тип> ...` | Создать таблицу с указанными столбцами |
| `list_tables` | Показать список существующих таблиц |
| `drop_table <имя_таблицы>` | Удалить таблицу с указанным именем |
| `exit` | Завершить работу программы |

### Пример использования

```text
$ database

СУБД запущена
Напишите help для получения справочной информации

>> help

Функции:

create_table <имя_таблицы> <столбец1:тип> <столбец2:тип> ... - создать таблицу
list_tables - показать список таблиц
drop_table <имя_таблицы> - удалить таблицу
exit - выйти из программы
help - справочная информация

>> create_table users name:str age:int
Таблица users создана

>> list_tables
users

>> drop_table users
Таблица users удалена

>> list_tables

>> exit
База данных завершила свою работу
```

## CRUD-операции

Для работы с данными предусмотрены следующие команды:

| Команда | Описание |
|---|---|
| `insert <имя_таблицы> <значение1> <значение2> ...` | Вставить строку в существующую таблицу |
| `select <имя_таблицы> [where <условие>]` | Вывести таблицу целиком или строки, соответствующие условию |
| `update <имя_таблицы> set <условие> where <условие>` | Изменить значение в записи таблицы |
| `delete <имя_таблицы> where <условие>` | Удалить строки, соответствующие условию |

Условие вводится через пробел в формате:

```text
<столбец> = <значение>
```

Параметр `[where <условие>]` в команде `select` является опциональным.

### Примеры использования CRUD-операций

**Создание таблицы и добавление записей:**

```text
>> create_table users name:str age:int
Таблица users создана

>> insert users Pasha 30
Данные записаны

>> insert users Ivan 28
Данные записаны

>> insert users Gena 30
Данные записаны
```

**Получение всех записей:**

```text
>> select users

+-------+-----+----+
|  name | age | ID |
+-------+-----+----+
| Pasha |  30 | 1  |
| Ivan  |  28 | 2  |
| Gena  |  30 | 3  |
+-------+-----+----+
```

**Фильтрация записей:**

```text
>> select users where age = 30

+-------+-----+----+
|  name | age | ID |
+-------+-----+----+
| Pasha |  30 | 1  |
| Gena  |  30 | 3  |
+-------+-----+----+
```

**Обновление записи:**

```text
>> update users set age = 30 where name = Ivan
Данные обновлены

>> select users

+-------+-----+----+
|  name | age | ID |
+-------+-----+----+
| Pasha |  30 | 1  |
| Ivan  |  30 | 2  |
| Gena  |  30 | 3  |
+-------+-----+----+
```

**Удаление записи:**

```text
>> delete users where name = Pasha
Записи удалены

>> select users

+------+-----+----+
| name | age | ID |
+------+-----+----+
| Ivan |  30 | 2  |
| Gena |  30 | 3  |
+------+-----+----+
```

## Декораторы

### Обработка ошибок (`handle_db_errors`)

Декоратор перехватывает следующие исключения:

- `KeyError` — обращение к несуществующему ключу.
- `ValueError` — некорректные значения или ошибки валидации.
- `FileNotFoundError` — отсутствие необходимого файла.

При возникновении ошибки программа выводит соответствующее сообщение в консоль.

### Подтверждение опасных операций (`confirm_action`)

Подтверждение запрашивается при выполнении следующих команд:

- `drop_table` — удаление таблицы.
- `delete` — удаление записей из таблицы.

Пример:

```text
>> drop_table users
Вы уверены, что хотите выполнить "удаление таблицы"? [y/n]: y
Таблица users удалена
```

Если пользователь вводит `y`, операция выполняется. При любом другом ответе операция отменяется.

### Замер времени выполнения (`log_time`)

Декоратор измеряет продолжительность выполнения следующих операций:

- `insert` — добавление новых записей в таблицу.
- `select` — получение записей из таблицы.

Пример вывода:

```text
>> select users
Функция select выполнилась за 0.001 секунд
```

### Кэширование запросов (`create_cacher`)

Реализована функция, использующая замыкание для хранения результатов запросов.

При повторном выполнении запроса `select` с теми же данными и условием результат может быть получен из кэша без повторной фильтрации данных.
