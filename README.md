Для управления таблицами используются следующие команды:


help - вывести справочную информацию

create_table <имя_таблицы> <столбец1:тип> <столбец2:тип> .. - создать таблицу с указанными столбцами

list_tables - показать список существующих таблиц

drop_table <имя_таблицы> - удалить таблицу с указанным именем

exit - завершить работу программы

$ database

CRUD-команды:


insert <имя_таблицы> <значение1> <значение2> <..> - вставить строку в существующую таблицу

select <имя_таблицы> [where <условие>] - вывести таблицу целиком или вывести строки с конкретным значением столбца

update <имя_таблицы> set <условие> where <условие> - заменить одно значение в записи таблицы

delete <имя_таблицы> where <условие> - удалить строку с указанным значением


<условие> вводится через пробел в виде <столбец> = <значение>

условие в [] опционально

Декораторы:

Обработка ошибок (handle_db_errors)


Перехватываются следующие исключения:


KeyError — обращение к несуществующему ключу.

ValueError — некорректные значения или ошибки валидации.

FileNotFoundError — отсутствие необходимого файла.

При возникновении ошибки программа выводит соответствующее сообщение в консоль.


Подтверждение опасных операций (confirm_action)


Подтверждение выводится при выполнении команд:

drop_table — удаление таблицы.

delete — удаление записей из таблицы

Пример:

>> drop_table users
Вы уверены, что хотите выполнить "удаление таблицы"? [y/n]: y
Таблица users удалена

Если пользователь вводит y, операция выполняется. При любом другом ответе операция отменяется.


Замер времени выполнения (log_time)


Декоратор измеряет продолжительность выполнения операций:

insert - занесение новых записей в таблицу

select - вывод записей из таблицы в консоль


Пример вывода:


>> select users
Функция select выполнилась за 0.001 секунд


Кэширование запросов (create_cacher())


Реализована функция, использующая замыкание для хранения результатов запросов.

При повторном выполнении одинакового запроса select результат может быть получен из кэша без повторной фильтрации данных.
