# Primitive DB

## Управление таблицами

Для управления таблицами используются следующие команды:

| Команда | Описание |
|---|---|
| `help` | Вывести справочную информацию |
| `create_table <имя_таблицы> <столбец1:тип> <столбец2:тип> ...` | Создать таблицу с указанными столбцами |
| `list_tables` | Показать список существующих таблиц |
| `drop_table <имя_таблицы>` | Удалить таблицу с указанным именем |
| `exit` | Завершить работу программы |

### Пример использования

```text
$ database

СУБД запущена
Напишите help для получения справочной информации

>> help

Функции:

create_table <имя_таблицы> <столбец1:тип> <столбец2:тип> ... - создать таблицу
list_tables - показать список таблиц
drop_table <имя_таблицы> - удалить таблицу
exit - выйти из программы
help - справочная информация

>> create_table users name:str age:int
Таблица users создана

>> list_tables
users

>> drop_table users
Таблица users удалена

>> list_tables

>> exit
База данных завершила свою работу
```

## CRUD-операции

Для работы с данными предусмотрены следующие команды:

| Команда | Описание |
|---|---|
| `insert <имя_таблицы> <значение1> <значение2> ...` | Вставить строку в существующую таблицу |
| `select <имя_таблицы> [where <условие>]` | Вывести таблицу целиком или строки, соответствующие условию |
| `update <имя_таблицы> set <условие> where <условие>` | Изменить значение в записи таблицы |
| `delete <имя_таблицы> where <условие>` | Удалить строки, соответствующие условию |

Условие вводится через пробел в формате:

```text
<столбец> = <значение>
```

Параметр `[where <условие>]` в команде `select` является опциональным.

### Примеры использования CRUD-операций

**Создание таблицы и добавление записей:**

```text
>> create_table users name:str age:int
Таблица users создана

>> insert users Pasha 30
Данные записаны

>> insert users Ivan 28
Данные записаны

>> insert users Gena 30
Данные записаны
```

**Получение всех записей:**

```text
>> select users

+-------+-----+----+
|  name | age
